# Automated Generation of Digital Product Passports Using Large Language Models

Supporting materials for *From Industrial Product Documentation to Automated Digital Product Passport Generation: An Experimental Study of Large Language Models* (NAMRC 55, 2027).

The study examines retrieval-augmented generation of AAS-based digital product passports from industrial product documentation. This repository contains the retained prompts, model configuration, experiment definitions and source references. The complete execution pipeline is not included but can be made available upon request.
